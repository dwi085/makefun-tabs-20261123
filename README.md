# How Many Tabs Do You Have Open?

Entry for the [make.fun bounty "How Many Tabs Do You Have Open?"](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d).

The program (`main.ts`, Node 22) writes exactly one number in digits and nothing else to `/output/entry.txt` — the entrant's honest count of open browser tabs right now: 47. Not a round guess and not a joke number — forty-seven tabs across two windows, the lived-in count of someone who researches in the browser all day, keeps docs open "to read later", and never quite closes anything. Deterministic: two runs produce byte-identical output.
